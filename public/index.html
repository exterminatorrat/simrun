Analysis

Simulated estimates, not measured values. GAP is an estimate: sec/km divided by clamp(1 + 4.5g + 13g², 0.70, 1.50), with 30 m smoothed grade clipped to ±15%. TRIMP uses the sex-agnostic Banister exponential estimate: minutes × HR reserve × 0.64 × e^(1.92 × HR reserve); default resting and maximum HR are 60 and 190 bpm.

Offline map data

Basemap resources you have already viewed are stored on this device, so the map can reload without a network. Viewed OpenFreeMap, OpenTopoMap and Waymarked Trails tiles are cached; routing, elevation and search always use the network.

Checking the offline cache…

    Viewed basemap tiles use a bounded cache. Route downloads prefetch the active vector-style tiles; OpenTopoMap and trail overlays are cached only after you view them.

    Routing options

    Applied to new routing requests only; existing routes are unchanged.

    Route data

    Default off. When enabled, the routed path is sent once to the selected Valhalla trace-attributes endpoint. Some routing services do not provide these details.

    Points of interest

    Default off. Choosing Find places sends up to 64 sampled route-corridor coordinates to the selected Overpass endpoint. Requests are one per action and can be cancelled.

    Open service endpoints

    HTTPS only. Compatible replacements must accept the same API. No private credentials.

    Routes, map views and searches reach the selected providers. GPX files, simulation, drafts and history stay local. Clearing site data removes saved activities; export a backup first.

    Trim or split route

    Distances are measured from the beginning of the current route, in km.

    Merge saved route

    The current route joins the selected activity end-to-end.

    A gap over 1 m is routed through the current provider. Gaps above 100 km are rejected; routing failure leaves the current route unchanged.

    Share this route
